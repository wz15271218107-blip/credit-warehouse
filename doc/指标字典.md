# 指标字典 · 信贷违约数仓

> 作用：让"违约率、平均利率"这些词有唯一精确的含义——范围、公式、维度、时间四要素写死，避免口径歧义。
> 数据基础：DWD 已终结贷款 38,979 笔（is_default 0/1 标签），时间 2007-06 ~ 2011-12。

## 0. 公共口径声明（全文通用）

| 要素 | 内容 |
|---|---|
| 违约定义 | loan_status IN (Charged Off, Default, Does not meet the credit policy. Status:Charged Off) → is_default = 1 |
| 正常定义 | loan_status IN (Fully Paid, Does not meet the credit policy. Status:Fully Paid) → is_default = 0 |
| 统计范围 | 已终结贷款 38,979 笔（剔除进行中 3,556 + 状态空 7 笔，Day 3 定案） |
| 时间范围 | 2007-06 ~ 2011-12 |
| 口径说明 | 本项目一人一笔（38,979 客户 = 38,979 笔），故"笔数口径"与"客户口径"结果相同；真实业务中一人可借多笔，两者会不同，报数必须声明用哪种 |
| 精度要求 | 关键指标用**计数列相除**精确重算（SUM(default_cnt)/SUM(loan_cnt)），不拿每行 ROUND 后的比率再平均（会累积舍入误差，0.1591 vs 0.1592 的差异即由此而来） |

## 1. 整体违约率

| 要素 | 内容 |
|---|---|
| 定义 | 全部已终结贷款中违约的占比 |
| 口径 | 笔数口径（本项目=客户口径） |
| 公式 | SUM(is_default) / COUNT(*) = 违约笔数 ÷ 总笔数 |
| 维度 | 整体，可下钻到地区/月份 |
| 数据来源 | dwd.fact_loan 或 dws 计数列（SUM(default_cnt)/SUM(loan_cnt)） |
| 当前值 | 6,203 / 38,979 = **0.1591（15.91%）** |

## 2. 各客群违约率（按地区）

| 要素 | 内容 |
|---|---|
| 定义 | 某州/地区已终结贷款中违约的占比 |
| 口径 | 笔数口径 |
| 公式 | 该地区违约笔数 ÷ 该地区总笔数（GROUP BY region_key） |
| 维度 | 州（region） |
| 数据来源 | dws.dws_region |
| 当前值 | 全量 Top5：CA 0.1732 / NY 0.1430 / FL 0.1982 / TX 0.1331 / NJ 0.1610；整体 0.1591 |
| 小样本处理（已定案） | 数据层**保留全部行**并标注样本量；展示层按门槛过滤（如样本 ≥ 50 才进排行）。原因：门槛丢弃数据、合并口径主观性强；NE（11 笔/54.55%）、ME（3 笔/0%）此类小样本比率仅供参考，不做结论 |

## 3. 各客群违约率（按月份）

| 要素 | 内容 |
|---|---|
| 定义 | 某个月放款在统计期内的违约占比 |
| 公式 | 该月违约笔数 ÷ 该月总笔数（GROUP BY year, month） |
| 维度 | 年月 |
| 数据来源 | dws.dws_date |
| 当前值 | 最高三个月：2007-10 0.3238 / 2007-11 0.3036 / 2008-01 0.2754（早期放款违约率高，后期批次尚未充分暴露） |

## 4. 平均利率

| 要素 | 内容 |
|---|---|
| 定义 | 全部已终结贷款的利率平均水平 |
| 口径 | 算术平均（每笔贷款权重相同） |
| 公式 | AVG(int_rate)（NULL 自动跳过；本项目 38,979 笔全部有利率） |
| 维度 | 整体，可下钻 |
| 数据来源 | dwd.fact_loan |
| 主口径（已定案） | **金额加权平均**（资金成本/收益视角）：SUM(loan_amnt × int_rate) ÷ SUM(loan_amnt) = **12.61%**——老板问"放贷收益"时用这个 |
| 备用口径 | 算术平均 AVG(int_rate) = 11.94%，用于"平均每笔贷款的客户利率/风险定价"视角 |
| 备注 | 两种口径并存但各有名字，避免"平均利率"歧义——这就是语义层 |

## 5. 放款金额

| 要素 | 内容 |
|---|---|
| 定义 | 放款规模 |
| 公式 | 总放款额 = SUM(loan_amnt)；平均单笔 = AVG(loan_amnt) |
| 维度 | 整体 / 地区 / 月份 |
| 数据来源 | dwd.fact_loan / dws 三表 |
| 当前值 | 总放款 **$417,052,675**；平均单笔 **$10,699.42**（38,979 笔） |

## 口径决议记录（Day 7，判断层成果）

| 议题 | 决议 | 理由 |
|---|---|---|
| 小样本州（NE 11 笔/54.55%、ME 3 笔/0%） | 数据层保留全部 + **标注样本量**；展示层按门槛过滤 | 门槛丢弃数据、合并小州口径主观性强；小样本比率仅供参考不作结论 |
| 平均利率口径 | **主口径：金额加权 12.61%**（资金收益视角）；备用：算术平均 11.94%（客户风险视角） | 老板问"放贷收益"时加权才真实；两种口径并存但各有名字，杜绝歧义 |
| 整体违约率精度 | 用计数相除精确重算（SUM(default_cnt)/SUM(loan_cnt)=0.1591） | 不拿 ROUND 后比率再平均（有舍入误差 0.1592 假象） |
| 笔数 vs 客户口径 | 本项目一人一笔，两口径相同；文档声明真实业务需区分 | 避免报表口径事故 |
