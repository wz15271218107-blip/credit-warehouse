## 第 3 周：可视化、调度、工程化（主线 DataEase + 加分 Power BI）

> **选型说明（双保险）**：央国企/城投场景信创要求下国产 BI（DataEase/帆软）更主流，
> 且你已有 DataEase 20+ 大屏经验（已投资产，复用零成本），故主线用 DataEase 保交付；
> Power BI 市场认知度高、DAX 是通用值钱技能，用剩余精力补上做"加分项"，简历两头都站得住。

| 天 | 任务 | 交付物 |
|---|---|---|
| Day 11 | DataEase 连 MySQL 接 ADS 数据集 | 数据集截图 |
| Day 12 | 大屏设计（总览/地区排行/月度趋势/客群分布） | 信贷监控大屏（主线交付） |
| Day 13 | 影刀 RPA 自动调度（每天跑 ODS→ADS→刷大屏）+ 安装 Power BI Desktop（免费）导入同一套 ADS 数据 | 自动化流程 + Power BI 数据集 |
| Day 14 | 全链路联调（原始→ADS→大屏，记录每步耗时）+ Power BI 做同款三张图（Power Query + 简单 DAX） | 链路图 + 耗时 + Power BI 图表 |
