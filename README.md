# 信贷违约数仓

基于 Lending Club 真实信贷数据构建的一套分层数仓实战项目：完成从原始数据落库、ODS 贴源、DWD 清洗打标签，到星型结构建模（事实表 + 维度表）的全流程，实现了违约口径的定义、违约标签化，以及按客户 / 日期 / 地区三个维度分析违约的能力。

## 数据来源

- Lending Club 贷款数据（LoanStats3a.csv，H2O 官方镜像）
- 42,542 行 × 52 列，2007-06 ~ 2011-12 真实信贷数据
- 覆盖字段：贷款金额、利率、期限、借款人收入/职位/住房、放款日期、地区、贷款状态等

## 技术栈

- MySQL 8.0 + MySQL Workbench
- Python 3（pymysql 批量导入脚本）
- Git / GitHub（全程版本管理）

## 数仓架构

四层分层：**原始进 ODS、洗干净进 DWD、按主题汇总进 DWS、给报表进 ADS**。

```
src.loan_raw → ods.loan_ods → dwd.loan_dwd → 星型结构（第 1 周）
                                    ↓
                        dws.* / ads.*（第 2 周）
```

架构细节见 [doc/架构图.md](doc/架构图.md)。

## 核心成果（第 1 周）

| 层 | 表 | 规模 | 说明 |
|---|---|---|---|
| src | loan_raw | 42,542 × 52 | 原始数据原样落库 |
| ods | loan_ods | 42,542 × 54 | +dt（数据日期）+ etl_time（入仓时间） |
| dwd | loan_dwd | 38,979 × 13 | 清洗后明细，违约标签 6,203 / 正常 32,776 |
| 维度 | dim_date / dim_region / dim_customer | 55 / 50 / 38,979 | 日期 / 地区 / 客户字典 |
| 事实 | fact_loan | 38,979 | 一笔贷款一行，3 外键 + 数字指标 |

清洗动作：口径过滤（剔除进行中贷款）、空行清理、双空格标准化、日期格式化（文本→日期）、利率转数值（%→小数）、缺失处理（职位填 Unknown、收入转 NULL）、违约打标签。

## 怎么跑

1. **建库建表 + 灌数**：执行 `sql/week1.sql`（四段按顺序，需先有 `src.loan_raw`）
2. **导入原始数据**（如库中无数据）：`scripts/import_csv_to_mysql.py`
3. **验证**：各层行数勾稽见 `doc/清洗记录.md`
